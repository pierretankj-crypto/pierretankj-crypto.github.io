02Projects作品

Built on my own time

Three projects I dreamed up and built with AI, from the first idea to the final polish.

01秘書

Chief of Staff

AI email & calendar assistant

Reads Gmail and Google Calendar, sorts every email into Reply, Delegate, Archive or FYI, saves reply drafts back to Gmail and preps each meeting before it starts.

  • Claude must answer in a strict JSON schema, which the server merges with live Gmail and Calendar data, so the model cannot invent an email or a meeting.
  • OAuth tokens encrypted with AES-256-GCM, HMAC-signed HttpOnly cookies, CSRF protection, per-user daily quotas and prompt-injection hardening.
  • An hourly GitHub Actions job calls a secret-protected serverless endpoint to send the morning and evening briefs.
  • Node.js
  • Claude API
  • Google OAuth 2.0
  • Upstash Redis
  • GitHub Actions
  • Vercel

02第二の脳

ZENOTH

Voice-first second brain

A voice assistant that writes every conversation and note into an Obsidian vault, then pulls the relevant notes back in as context for the next answer.

  • A rule-based router classifies each request in under 1 ms with no model call: simple requests go to rules, light tasks to Claude Haiku, heavy jobs to background Claude Code sessions.
  • An 8-endpoint FastAPI bridge for vault access, chat, background jobs, speech-to-text and text-to-speech, token-protected and bound to localhost.
  • Speech runs locally, with faster-whisper listening and Kokoro speaking.
  • JavaScript
  • Python
  • FastAPI
  • Claude API
  • faster-whisper
  • Kokoro

03家計簿

Petal Finance

Offline-first finance tracker (PWA)

An installable app for budgets, savings goals and net worth that keeps working with no connection, in about 3,800 lines of framework-free code.

  • A custom SVG chart engine with no chart library: donut, line, column and bar charts with tooltips and animated transitions.
  • CSV export and a Ctrl+K command palette for every action.
  • Stored data sanitised, user input escaped against XSS, WCAG AA contrast and full keyboard navigation.
  • JavaScript
  • SVG
  • Service Workers
  • PWA
